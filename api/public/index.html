接入方式（OpenAI 兼容）

把 base_url 指向本平台，用你的 sk- 令牌即可，无需改代码。

curl http://127.0.0.1:58881/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ***你的令牌" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [{"role":"user","content":"你好"}],
    "stream": false
  }'

Python (openai SDK)

from openai import OpenAI
client = OpenAI(
    base_url="http://127.0.0.1:58881/v1",
    api_key="***",
)
r = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[{"role": "user", "content": "你好"}],
)
print(r.choices[0].message.content)

可用端点

  • GET /v1/models — 列出令牌可见模型
  • POST /v1/chat/completions — 对话补全（支持 stream）
  • POST /v1/completions — 文本补全
  • POST /v1/embeddings — 向量

错误码

  • 401 令牌无效 / 过期
  • 402 余额或令牌额度不足
  • 403 令牌禁用 / 模型无权 / IP 不白名单
  • 429 触发限流（响应头带 Retry-After）
  • 502/503 上游全部不可用（自动故障转移后仍失败）
